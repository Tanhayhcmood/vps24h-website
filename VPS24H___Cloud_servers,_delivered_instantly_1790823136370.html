    Frequently asked

    Which operating systems are available?

    Ubuntu, Debian, Rocky, AlmaLinux, CentOS Stream, Oracle Linux, Fedora, openSUSE, Arch, Kali, FreeBSD, OpenBSD and Windows Server.

    How do I connect to a Linux server?

    Open a terminal and run ssh root@YOUR_IP using the IP and password from your dashboard.

    How do I connect to Windows Server?

    Use Remote Desktop (RDP) with the server IP, the user Administrator and the password from your dashboard.

    How do I change my root password?

    Log in over SSH and run the passwd command, then enter the new password twice.

    How do I open a port?

    On Ubuntu or Debian run ufw allow 80/tcp. On Windows Server add an inbound rule in Windows Defender Firewall.
